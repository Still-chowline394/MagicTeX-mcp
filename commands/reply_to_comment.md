Call the `reply_to_comment` MCP tool to add a threaded reply to an existing
comment. Read the comment id and the reply text from **$ARGUMENTS**. Use this to
respond to my feedback, or as the `author`/`defender` role in a review thread
before I resolve it. If no id is given, ask me which comment to reply to.
