Call the `add_comment` MCP tool to anchor a comment onto the paper. Read the
*exact quoted passage* and the note from **$ARGUMENTS**. Use `role: "reviewer"`
for a suggested change, or `role: "defender"` when challenging a claim. The comment
appears anchored on the PDF for me to Accept or Reject — **don't edit the source**.
